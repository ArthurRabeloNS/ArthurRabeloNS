## Projetos em destaque

### [SteveCube v0.7.3](https://github.com/ArthurRabeloNS/Jogos_Games)

Modificação (mod) que adiciona o **Steve, de Minecraft, como chef jogável em Overcooked! 2**. O projeto envolveu **engenharia reversa** para descompilar, analisar e estender o código C# original do jogo.

**Tecnologias:** `C#` · `dnSpy` · `Unity`

<sub>Projeto independente de fã, sem vínculo com a Mojang Studios, a Microsoft, a Team17 ou a Ghost Town Games. Minecraft e Overcooked! 2 são marcas de seus respectivos proprietários.</sub>

### [Interativo](https://github.com/ArthurRabeloNS/Interativo)

Aplicação de **visão computacional** voltada à interação em tempo real. O sistema realiza reconhecimento facial e rastreamento de gestos, permitindo **pintar digitalmente usando apenas o movimento das mãos**.

**Tecnologias:** `Python` · `OpenCV`
